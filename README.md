# Visualising and Communicating Data - course files

## Where to start
1. Open `ASDXDDL8M7_LABSDayOne.pdf` - the Power BI lab book.
2. For each lab, open the `Start` file in that lab's folder.
3. The `After Exercise` files show the finished result of each exercise.

## What's here
- `slides/` - course presentations
- `ASDXDDL8M7_LABSDayOne.pdf` - Power BI lab book
- `lab09` - `lab18` - Power BI lab files
- `DG_01_Workbook_ASDXDDL8M7.docx` - Data Storytelling workbook
- `QuantitativeData.xlsx`, `SampleReportXL.xlsx` - Data Storytelling exercise files
- Other PDFs - reading and activities
- `Useful Links.txt` - useful links
